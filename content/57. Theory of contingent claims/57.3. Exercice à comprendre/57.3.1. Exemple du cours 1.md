### Cadre du modèle

L'univers des états est $\Omega = \{\omega_1, \omega_2, \omega_3\}$.

* En $t = 0$ : $S_0^0 = 1$, $S_0^1 = 100$, $S_0^2 = 100$.
* En $t = T$ : $S_T^0 = 1 + r$, avec les vecteurs de prix :

$$S_T^1 = \begin{pmatrix} 88 \\ 110 \\ 132 \end{pmatrix}, \quad S_T^2 = \begin{pmatrix} 132 \\ 88 \\ 110 \end{pmatrix}$$

---

### Question 1 : Cas avec taux fixé $r = 10\%$

Le marché vérifie l'absence d'opportunité d'arbitrage (AOA) si et seulement s'il existe une mesure martingale équivalente $\mathbb{Q} = (q_1, q_2, q_3)$ vérifiant :

$$q_1 > 0, \quad q_2 > 0, \quad q_3 > 0, \quad q_1 + q_2 + q_3 = 1$$

et les conditions d'espérance actualisée :

$$\mathbb{E}^\mathbb{Q}[S_T^1] = (1+r)S_0^1 = 110, \quad \mathbb{E}^\mathbb{Q}[S_T^2] = (1+r)S_0^2 = 110$$

Ce qui donne le système linéaire :

$$\begin{cases} q_1 + q_2 + q_3 = 1 \quad (L_1) \\ 88 q_1 + 110 q_2 + 132 q_3 = 110 \quad (L_2) \\ 132 q_1 + 88 q_2 + 110 q_3 = 110 \quad (L_3) \end{cases}$$

En divisant $(L_2)$ et $(L_3)$ par 22 :

$$\begin{cases} 4 q_1 + 5 q_2 + 6 q_3 = 5 \\ 6 q_1 + 4 q_2 + 5 q_3 = 5 \end{cases}$$

Soustraction $(L_3) - (L_2)$ :

$$2 q_1 - q_2 - q_3 = 0 \implies q_2 + q_3 = 2 q_1$$

En remplaçant dans $(L_1)$ :

$$q_1 + 2 q_1 = 1 \implies q_1 = \frac{1}{3}$$

On a donc $q_2 + q_3 = \frac{2}{3}$. En reportant dans $(L_2)$ :

$$4\left(\frac{1}{3}\right) + 5 q_2 + 6\left(\frac{2}{3} - q_2\right) = 5 \implies \frac{4}{3} + 4 - q_2 = 5 \implies q_2 = \frac{1}{3}$$

Puis :

$$q_3 = \frac{2}{3} - \frac{1}{3} = \frac{1}{3}$$

L'unique mesure martingale est :

$$\mathbb{Q} = \left(\frac{1}{3}, \, \frac{1}{3}, \, \frac{1}{3}\right)$$

Toutes les probabilités étant strictement positives, **l'AOA est vérifiée** (et le marché est complet du fait de l'unicité).

### Question 1 bis : Intervalle d'AOA pour $r$ quelconque

On cherche l'ensemble des valeurs de $r$ garantissant l'existence d'une mesure $\mathbb{Q} = (q_1, q_2, q_3)$ strictement positive telle que :

$$\begin{cases} q_1 + q_2 + q_3 = 1 \quad (1) \\ 88 q_1 + 110 q_2 + 132 q_3 = 100(1+r) \quad (2) \\ 132 q_1 + 88 q_2 + 110 q_3 = 100(1+r) \quad (3) \end{cases}$$

En soustrayant $(2)$ à $(3)$ :

$$44 q_1 - 22 q_2 - 22 q_3 = 0 \implies 2 q_1 = q_2 + q_3$$

Avec $(1)$, la valeur de $q_1$ reste invariante :

$$q_1 = \frac{1}{3} \quad \text{et} \quad q_3 = \frac{2}{3} - q_2$$

En injectant dans l'équation $(2)$ :

$$88\left(\frac{1}{3}\right) + 110 q_2 + 132\left(\frac{2}{3} - q_2\right) = 100(1+r)$$

$$\frac{352}{3} - 22 q_2 = 100 + 100r \implies 22 q_2 = \frac{52}{3} - 100r$$

D'où :

$$q_2 = \frac{26}{33} - \frac{50}{11}r$$

$$q_3 = \frac{2}{3} - q_2 = -\frac{4}{33} + \frac{50}{11}r$$

Conditions de stricte positivité :

* $q_1 = \frac{1}{3} > 0$ (toujours vrai)
* $q_2 > 0 \iff \frac{50}{11}r < \frac{26}{33} \iff r < \frac{26}{150} = \frac{13}{75}$
* $q_3 > 0 \iff \frac{50}{11}r > \frac{4}{33} \iff r > \frac{4}{150} = \frac{2}{75}$

L'intervalle d'AOA pour $r$ est :

$$I = \left] \frac{4}{150}, \, \frac{26}{150} \right[ = \left] \frac{2}{75}, \, \frac{13}{75} \right[$$

### Question 2 : Portefeuille de couverture du Put ($K = 105$)

Le payoff terminal du Put sur $S^1$ vaut $X = (105 - S_T^1)^+$ :

* $X(\omega_1) = (105 - 88)^+ = 17$
* $X(\omega_2) = (105 - 110)^+ = 0$
* $X(\omega_3) = (105 - 132)^+ = 0$

On résout le système de réplication $V_T(\theta) = X$ pour $\theta = (\theta^0, \theta^1, \theta^2)$ :

$$\begin{cases} (1+r)\theta^0 + 88 \, \theta^1 + 132 \, \theta^2 = 17 \quad (1) \\ (1+r)\theta^0 + 110 \, \theta^1 + 88 \, \theta^2 = 0 \quad (2) \\ (1+r)\theta^0 + 132 \, \theta^1 + 110 \, \theta^2 = 0 \quad (3) \end{cases}$$

**Composantes risquées :**

* $(3) - (2) \implies 22 \, \theta^1 + 22 \, \theta^2 = 0 \implies \theta^2 = -\theta^1$
* $(2) - (1) \implies 22 \, \theta^1 - 44 \, \theta^2 = -17$
* Substitution : $22 \, \theta^1 + 44 \, \theta^1 = -17 \implies 66 \, \theta^1 = -17$

$$\theta^1 = -\frac{17}{66}, \quad \theta^2 = \frac{17}{66}$$

**Composante sans risque :**
En remplaçant dans $(2)$ :

$$(1+r)\theta^0 + 110\left(-\frac{17}{66}\right) + 88\left(\frac{17}{66}\right) = 0 \implies (1+r)\theta^0 - \frac{17}{3} = 0$$

$$\theta^0 = \frac{17}{3(1+r)}$$

**Prix initial du Put :**

$$V_0 = \theta^0 + 100 \, \theta^1 + 100 \, \theta^2 = \frac{17}{3(1+r)}$$

Pour $r = 10\%$ :

$$\theta = \left(\frac{170}{33}, \, -\frac{17}{66}, \, \frac{17}{66}\right) \approx (5{,}1515, \, -0{,}2576, \, 0{,}2576)$$

$$V_0 = \frac{170}{33} \approx 5{,}15$$
