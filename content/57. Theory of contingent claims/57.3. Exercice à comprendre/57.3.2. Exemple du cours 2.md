### Cadre du modèle

L'univers des états est $\Omega = \{\omega_1, \omega_2, \omega_3\}$.
Deux actifs risqués $S^1$ et $S^2$ ont pour rendements bruts $\frac{S^i_T}{S^i_0}$ :

$$\frac{S^1_T}{S^1_0}(\omega_1) = \frac{42}{31}, \quad \frac{S^1_T}{S^1_0}(\omega_2) = \frac{21}{31}, \quad \frac{S^1_T}{S^1_0}(\omega_3) = \frac{21}{62}$$

$$\frac{S^2_T}{S^2_0}(\omega_1) = \frac{21}{124}, \quad \frac{S^2_T}{S^2_0}(\omega_2) = \frac{42}{31}, \quad \frac{S^2_T}{S^2_0}(\omega_3) = \frac{168}{31}$$

Les probabilités historiques a priori sont $\mathbb{P}(\omega_1) = 1/8, \mathbb{P}(\omega_2) = 3/8, \mathbb{P}(\omega_3) = 4/8$.

### Question 1 : Cas avec taux sans risque fixé $r = 5\%$

Le marché vérifie l'absence d'opportunité d'arbitrage (AOA) si et seulement s'il existe une mesure martingale équivalente $\mathbb{Q} = (q_1, q_2, q_3)$ vérifiant :
$$q_1 > 0, \quad q_2 > 0, \quad q_3 > 0, \quad q_1 + q_2 + q_3 = 1$$

et les conditions d'espérance actualisée avec $1+r = 1.05 = \frac{21}{20}$ :
$$\mathbb{E}^\mathbb{Q}\left[\frac{S^1_T}{S^1_0}\right] = \frac{21}{20}, \quad \mathbb{E}^\mathbb{Q}\left[\frac{S^2_T}{S^2_0}\right] = \frac{21}{20}$$

Ce qui donne le système linéaire sur les rendements :
$$\begin{cases} q_1 + q_2 + q_3 = 1 \\ \frac{42}{31} q_1 + \frac{21}{31} q_2 + \frac{21}{62} q_3 = \frac{21}{20} \\ \frac{21}{124} q_1 + \frac{42}{31} q_2 + \frac{168}{31} q_3 = \frac{21}{20} \end{cases}$$

La résolution donne l'unique solution :
$$q_1 = \frac{3}{5} = 0.6, \quad q_2 = \frac{3}{10} = 0.3, \quad q_3 = \frac{1}{10} = 0.1$$

Comme toutes les probabilités sont strictement positives, **le marché est sans opportunité d'arbitrage (AOA)** et **complet** (unicité de l'E.M.M.).

### Question 1 bis : Variante du prof — Intervalle d'AOA pour un taux $r$ quelconque

On cherche l'ensemble des valeurs du taux sans risque $r$ garantissant l'existence d'une mesure $\mathbb{Q} = (q_1, q_2, q_3)$ strictement positive vérifiant :
$$\begin{cases} q_1 + q_2 + q_3 = 1 \\ \frac{42}{31} q_1 + \frac{21}{31} q_2 + \frac{21}{62} q_3 = 1+r \\ \frac{21}{124} q_1 + \frac{42}{31} q_2 + \frac{168}{31} q_3 = 1+r \end{cases}$$

**1. Simplification du système :**
Multiplions la 2e équation par $\frac{62}{21}$ :
$$4 q_1 + 2 q_2 + q_3 = \frac{62}{21}(1+r)$$

Multiplions la 3e équation par $\frac{124}{21}$ :
$$q_1 + 8 q_2 + 32 q_3 = \frac{124}{21}(1+r)$$

Comme $q_3 = 1 - q_1 - q_2$, la première relation devient :
$$4 q_1 + 2 q_2 + (1 - q_1 - q_2) = \frac{62}{21}(1+r)$$
$$3 q_1 + q_2 + 1 = \frac{62}{21} + \frac{62}{21} r \implies q_2 = \frac{41}{21} + \frac{62}{21} r - 3 q_1$$

En substituant $q_3 = 1 - q_1 - q_2$ dans la deuxième relation :
$$q_1 + 8 q_2 + 32(1 - q_1 - q_2) = \frac{124}{21}(1+r)$$
$$-31 q_1 - 24 q_2 + 32 = \frac{124}{21}(1+r)$$
$$31 q_1 + 24 q_2 = \frac{548}{21} - \frac{124}{21} r$$

En substituant $q_2$ :
$$31 q_1 + 24\left( \frac{41}{21} + \frac{62}{21} r - 3 q_1 \right) = \frac{548}{21} - \frac{124}{21} r$$
$$-41 q_1 = -\frac{436}{21} - \frac{1612}{21} r$$

On obtient donc analytiquement :
$$q_1(r) = \frac{436}{861} + \frac{1612}{861} r$$

$$q_2(r) = \frac{373}{861} - \frac{2294}{861} r$$

$$q_3(r) = \frac{52}{861} + \frac{682}{861} r$$

**2. Conditions d'AOA (stricte positivité) :**
- $q_1(r) > 0 \iff r > -\frac{436}{1612} = -\frac{109}{403} \approx -27.05\%$
- $q_2(r) > 0 \iff r < \frac{373}{2294} \approx 16.26\%$
- $q_3(r) > 0 \iff r > -\frac{52}{682} = -\frac{26}{341} \approx -7.62\%$

L'intervalle d'absence d'arbitrage pour le taux sans risque $r$ est :
$$I = \left] -\frac{26}{341}, \; \frac{373}{2294} \right[ \approx \left] -7.62\%, \; 16.26\% \right[$$

*(Si l'on impose de surcroît la condition usuelle de positivité du taux nominal $r \ge 0$, on obtient $r \in [0, \frac{373}{2294}[$).*

### Question 2 : Pricing et couverture d'un Call sur $S^2$

On s'intéresse à un Call sur $S^2$ de strike $K = \frac{150}{31} S^2_0$.
Le payoff à l'échéance est $X = \left(S^2_T - \frac{150}{31} S^2_0\right)^+$ :
- En $\omega_1$ : $\frac{21}{124} < \frac{150}{31} \implies X(\omega_1) = 0$
- En $\omega_2$ : $\frac{42}{31} < \frac{150}{31} \implies X(\omega_2) = 0$
- En $\omega_3$ : $\frac{168}{31} > \frac{150}{31} \implies X(\omega_3) = \frac{168 - 150}{31} S^2_0 = \frac{18}{31} S^2_0$

**1. Prix sous mesure risque-neutre $\mathbb{Q}$ :**
$$\Pi_0(X)(r) = \mathbb{E}^\mathbb{Q}\left[ \frac{X}{1+r} \right] = \frac{q_3(r)}{1+r} \times \frac{18}{31} S^2_0$$

Pour $r = 5\%$ :
$$\Pi_0(X) = \frac{1/10}{21/20} \times \frac{18}{31} S^2_0 = \frac{12}{217} S^2_0 \approx 0.0553 S^2_0$$

**2. Portefeuille de couverture :**
La condition $V_T(\theta) = X$ s'écrit matriciellement $R \Theta = X$, conduisant à :
$$\begin{pmatrix} \theta^0 S^0_0 \\ \theta^1 S^1_0 \\ \theta^2 S^2_0 \end{pmatrix} = S^2_0 \begin{pmatrix} -\frac{3600}{8897} \\ \frac{12}{41} \\ \frac{48}{287} \end{pmatrix}$$

La valeur initiale du portefeuille de réplication est :
$$V_0(\theta) = S^2_0 \left( -\frac{3600}{8897} + \frac{12}{41} + \frac{48}{287} \right) = \frac{12}{217} S^2_0$$
Ce qui confirme rigoureusement le théorème de valorisation par arbitrage : $V_0(\theta) = \Pi_0(X)$.
